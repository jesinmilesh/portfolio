Project Overview

Technologies Used

  • Python 3: Application engine & formatting logic
  • Scapy: Raw socket packet capture, binding, and packet dissection
  • Colorama: Visual terminal output highlighting
  • OS Sockets: Direct network interface integration

Problem Solved

Understanding raw network data flowing through an interface is difficult without complex tools. This lightweight CLI packet sniffer decodes Ethernet, IP, TCP, and UDP layers on the fly, rendering structured packet fields to the terminal for fast network debugging and vulnerability detection.

Key Highlights

  • Live packet interception on any active network interface.
  • Structured output showing IP sources, destinations, ports, and protocol flags.
  • Hex payload dump rendering for packet content inspections.
  • No external system GUI dependencies, running cleanly in terminal windows.
