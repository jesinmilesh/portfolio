Core Technical Design

Posture Score Logic

The Cyber Health Posture score aggregates data streams into a single weighted score from 0 to 100%:

Score = (Security + Privacy + Network + Device + Checklist + Password + AppRisk) / 7

Scores update reactively based on events like toggling VPN (+25 points), network socket shifts, or security configurations change.

Security & Cryptography

  • Zero Remote Storage: Absolutely no metrics, passwords, or logs leave the local device storage.
  • AES Encription: System profiles and cached secrets are stored securely (DPAPI on Windows, Keystore/AES-Encrypted SharedPreferences on Android).
  • SHA-256 Hashing: Safe credentials gatekeeping without raw password exposures.

Engineering Stack

  • Flutter & Dart: Single codebase rendering native desktop and mobile frameworks.
  • Reactive Services: ValueNotifier and ChangeNotifier integrated with ListenableBuilder for lightweight, lag-free UI updates.
  • Platform Channels: Native interop through structured MethodChannels communicating with low-level OS telemetry libraries.
