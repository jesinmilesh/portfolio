Project Overview

Technologies Used

  • Shannon Entropy Engine: True information-theoretic randomness measurement $H = -\sum p_i \log_2(p_i)$.
  • Offensive Mask Matcher: Structural pattern detection identifying l33t speak, keyboard walks, and dates.
  • 30.4M Threat Corpus: Pre-indexed breach corpus detection for instant leak identification.
  • Chart.js & Dynamic Visualizations: Real-time entropy graphs, vulnerability ratings, and strength breakdown.

Problem Solved

Traditional password checkers approve predictable passwords like Summer2024! because they meet naive static rules (length, uppercase, symbol). However, modern GPU clusters crack such passwords in seconds using dictionary mask attacks. This platform simulates real adversary attack mechanics to deliver actionable security intelligence.

Key Highlights

  • Comprehensive 6-Step Workflow Tracker guiding security evaluation.
  • Multi-tier hardware crack time benchmarks from consumer CPUs to enterprise GPU clusters.
  • Real-time actionable remediation advice to eliminate high-risk patterns.
  • Full offensive attack simulation without compromising user credential privacy.

Attack Vector Resistance

  • Dictionary & Rule-Based Attacks: Exposes common dictionary stems and standard rule mutators.
  • Structural Mask Cracking: Detects predictable token arrangements like ?u?l?l?l?d?d?s.
  • Credential Stuffing Defense: Evaluates susceptibility to automated spray and credential stuffing.
