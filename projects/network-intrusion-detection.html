Project Overview

Technologies Used

  • Python 3: Rules evaluation engine and socket handler
  • Scapy: Network sniffing and raw header field mapping
  • Regular Expressions: Matching bytes patterns in payload segments
  • Logging API: Real-time structured notification storage

Problem Solved

Simple network capture scripts collect traffic logs without identifying security risk. This IDS continuously checks packet layers against custom alert definitions, enabling developers and administrators to immediately spot active scanning, unauthorized request paths, or packet flood conditions.

Key Highlights

  • Dynamic rule loading to scan packet payloads for exploit strings.
  • Threshold configurations to block Syn Flood and DoS/DDoS vectors.
  • Color-coded logging of warning levels (Info, Alert, Critical).
  • Easily extensible to integrate with SIEM monitoring tools.
