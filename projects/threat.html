Project Overview

Technologies Used

  • Python 3: Core scripting
  • psutil: Real-time network socket tracking
  • win32evtlog: Windows Security Event parsing
  • socket: IP resolution and tracking
  • PyInstaller: Standalone executable build

Problem Solved

System administrators need instant visibility into anomalous activities. This tool automates the process of combing through dense Windows event logs and active network connections, instantly flagging unauthorized access attempts or suspicious IP behavior.

Key Highlights

  • Real-time tracking of TCP/UDP network connections.
  • Automated identification of malicious signatures.
  • Direct integration with Windows Event Logs (Security channel).
  • Packaged as a standalone Windows executable for easy deployment.
