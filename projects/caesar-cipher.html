An interactive cryptosystem demonstrator implementing the classical Caesar substitution cipher. Performs mathematical character rotation modulo 26, preserving punctuation, casing, and spaces while illustrating fundamental cryptographic principles.

Substitution Cryptosystem

Project Overview

Technologies Used

  • HTML5 Architecture: Structured input fields, key controls, and read-only output panels.
  • CSS3 Glassmorphic Styling: Card containers with dynamic hover micro-animations and responsive spacing.
  • Vanilla JavaScript (ES6): ASCII character-code math, string transformations, and state resets.
  • Modular Arithmetic: Formula: $E(x) = (x + k) \pmod{26}$, $D(x) = (x - k) \pmod{26}$.

Problem Solved

Learning classical cryptography is essential for understanding modern symmetric encryption foundations, cryptanalysis, and frequency analysis. This tool delivers a tactile, instant visualization of substitution shifts and ciphertext decryption.

Key Highlights

  • Zero-dependency native client-side execution requiring no backend server.
  • Automatic shift value sanitization restricting keys to $1 \le k \le 25$.
  • Integrated clipboard copy with contextual feedback modal dialogs.
  • One-click state clearing for fast multiple experiments and demos.

Cryptographic Concepts

  • Monoalphabetic Substitution: Replacing each plaintext character with a character a fixed number of positions down the alphabet.
  • Keyspace Analysis: Demonstrates why a small keyspace (25 possible shifts) is vulnerable to brute-force frequency analysis.
  • Modular Inversion: Demonstrating how decryption is the inverse operation: $(26 - k) \pmod{26}$.
